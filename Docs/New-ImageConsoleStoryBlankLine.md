# New-ImageConsoleStoryBlankLine
## SYNOPSIS
Creates a blank-line step for an ImagePlayground console story.

## SYNTAX
### __AllParameterSets
```powershell
New-ImageConsoleStoryBlankLine [<CommonParameters>]
```

## DESCRIPTION
Creates a blank-line step for an ImagePlayground console story.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-ImageConsoleStoryBlankLine
```

Adds one blank terminal line.

- `None`

## OUTPUTS

- `ImagePlayground.PowerShell.ImageConsoleStoryStep` — Use the New-ImageConsoleStoryCommand, New-ImageConsoleStoryOutput, New-ImageConsoleStoryTable, New-ImageConsoleStoryBlankLine, and New-ImageConsoleStoryPause cmdlets to create steps.
