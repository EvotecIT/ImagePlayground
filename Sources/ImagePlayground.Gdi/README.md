# ImagePlayground.Gdi

> Deprecated: this package is retained for existing Windows-only GDI+ integrations. Do not use it for new applications.

Use the main [`ImagePlayground`](https://www.nuget.org/packages/ImagePlayground) package for image manipulation. Use [`ChartForgeX`](https://www.nuget.org/packages/ChartForgeX) for new chart rendering.

`ImagePlayground.Gdi` targets .NET Framework 4.7.2 and Windows-specific .NET 8/.NET 10. Its public API remains available as a compatibility engine for applications that cannot yet migrate from `System.Drawing`.
